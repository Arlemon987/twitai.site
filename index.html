Install Twit AI on iOS

Install this web application directly to your iPhone or iPad home screen:

1
Tap the Share button in Safari's bottom toolbar ().
2
Scroll down and select "Add to Home Screen" ().
3
Tap Add in the top right corner.

Install Twit AI on Mac

Install Twit AI as a standalone desktop app on macOS:

In Safari:
Click the top menu File → "Add to Dock..." to use it as a native Mac app.
In Chrome / Edge:
Click the Install icon in the address bar (top right) or menu (⋮) → "Install Twit AI".
